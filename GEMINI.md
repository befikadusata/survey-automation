# Project Instructions: Survey Automation

## Specialized Agents
This project has access to the `agency-agents` extension. For complex tasks, consider utilizing the following agents:
- `workflow-architect`: For mapping out survey flows and system integrations.
- `codebase-onboarding-engineer`: For exploring the existing survey automation logic.
- `reality-checker`: For verifying that implementations meet requirements.
- `git-workflow-master`: For maintaining a clean commit history.

## Development Workflow
- Follow the Research -> Strategy -> Execution lifecycle.
- Use `n8n` for workflow automation as identified in `n8n-workflows/`.
- Adhere to Next.js conventions as specified in `app/AGENTS.md`.
